# C++ Library Management System

## About the Project
This is a C++ based Library Management System developed as a university programming project. It helps manage library books through a simple menu-driven program.

## Features
- Add new books
- Display all books
- Search for books
- Update book information
- Issue books
- Return books
- Delete books

## C++ Concepts Used
- Variables and Data Types
- Constants
- Operators
- Input and Output (`cin` and `cout`)
- Conditional Statements (`if`, `if-else`, `switch`)
- Loops (`for`, `do-while`)
- User-Defined Functions
- Function Prototypes

## How to Run
1. Download the `.cpp` file.
2. Open it in Dev-C++ or another C++ IDE.
3. Compile the program.
4. Run the program.
5. Choose an option from the menu.

## Technologies Used
- C++
- Dev-C++

## Project Purpose
The purpose of this project is to practice basic C++ programming concepts and develop problem-solving skills.
